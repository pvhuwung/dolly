# Graphics

GENERATED by `npm run library`: don't edit it. Charts, numbers, pointers, input and product UI to put over any scene. Each takes `start` (the frame it begins) and most take `exit`.

`preview.jpg` shows every one: each cell is an item's sample, labelled with its code.

## Draw · `graphics/draw`

An SVG path that draws itself on, and off again: a hand-drawn underline, a scribble, a route.

`<Draw d="M6 26 C 110 10, 250 8, 414 20" width={420} height={40} start={10} />`

- `d: string` The SVG path to draw, in a `width` × `height` box.
- `width: number` Its width in px: the box `d` is drawn in.
- `height: number` Its height in px: the box `d` is drawn in.
- `start?: number` Frame it starts on, counted from the start of its scene (default 0).
- `frames?: number` Frames the line takes to draw (default 36).
- `exit?: number` Frame it starts to undraw; it stays to the end if not set.
- `color?: string` Its colour; the style's accent if not set.
- `strokeWidth?: number` Line width in px (default 6).
- `stretch?: boolean` Let `style` size the box to any width and height, stretching the path: for an underline as wide as its word.
- `style?: React.CSSProperties` CSS for the SVG, to place or size it.

## Arrow · `graphics/arrow`

A curved, hand-drawn arrow that draws itself from one point to another, its head landing last.

`<Arrow from={{x: 620, y: 360}} to={{x: 1180, y: 560}} start={10} />`

- `from: Pt` Where it starts, in px of its parent.
- `to: Pt` Where the head lands, in px of its parent.
- `bend?: number` How much it curves: 0 is straight, more bows it to the left of travel, less to the right (default 0.25).
- `start?: number` Frame it starts on, counted from the start of its scene (default 0).
- `frames?: number` Frames the line takes to draw (default 28).
- `exit?: number` Frame it starts to leave; it stays to the end if not set.
- `color?: string` Its colour; the style's accent if not set.
- `strokeWidth?: number` Line width in px (default 6).
- `head?: number` Length of the head's two strokes in px (default 26).

- `exit?: number` Frame it starts to leave; it stays to the end if not set.

## Bars · `graphics/bars`

A bar chart whose bars grow in one after another, values counting up, one bar highlighted.

`<Bars data={[{label: 'Jan', value: 12}, {label: 'Feb', value: 19}]} highlight={1} start={6} />`

- `data: { label: string; value: number; }[]` The bars, in order: a label and a value each.
- `highlight?: number` Index of the bar drawn in the accent.
- `across?: boolean` Lay the bars on their side with the labels on the left: for named categories, and for many bars in a tall frame.
- `width?: number` Its width in px (default 900).
- `height?: number` Its height in px (default 480).
- `start?: number` Frame it starts on, counted from the start of its scene (default 0).
- `stagger?: number` Frames between one bar starting to grow and the next (default 5).
- `max?: number` The value a full bar stands for; the largest value if not set.
- `format?: (n: number) => string` How a value is written (default a whole number with thousands separators).
- `exit?: number` Frame it starts to leave; it stays to the end if not set.

## Stat · `graphics/stat`

A big number counting up, its label under it, with an optional delta chip.

`<Stat value={12400} label="teams shipping" start={6} />`

- `value: number` The number it counts up to.
- `label?: string` Words under the number.
- `prefix?: string` Before the number, like '$'.
- `suffix?: string` After the number, like '%' or 'k'.
- `decimals?: number` Decimal places shown (default 0).
- `delta?: string` A small chip beside the number once the count lands, like '+38%'.
- `start?: number` Frame it starts on, counted from the start of its scene (default 0).
- `frames?: number` Frames the count takes (default 50).
- `size?: number` Size of the number in px; twice the style's headline size if not set.
- `align?: 'left' | 'center'` 'center' puts the label under the middle of the number, 'left' lines both up on the left (default 'center').
- `exit?: number` Frame it starts to leave; it stays to the end if not set.

## Burst · `graphics/burst`

Confetti bursting from a point and falling away under gravity: a success moment.

`<Burst x={960} y={500} start={14} />`

- `x: number` Where it bursts from, in px of its parent.
- `y: number` Where it bursts from, in px of its parent.
- `start?: number` Frame it bursts on, counted from the start of its scene (default 0).
- `count?: number` How many pieces of confetti (default 80).
- `power?: number` How big and far it bursts; 1 is normal (default 1).
- `seed?: string` Changes the pattern, so two bursts don't match (default 'burst').
- `colors?: string[]` Colours of the confetti; the accent, the alert colour, a light accent and the ink if not set.

## Shine · `graphics/shine`

A glint of light sweeping across its children, once or on a loop.

`<Shine start={20} every={50}><div>Get early access</div></Shine>`

- `start?: number` Frame the first glint starts on, counted from the start of its scene (default 0).
- `frames?: number` Frames one sweep takes (default 30).
- `every?: number` Sweep again every this many frames; just once if not set.
- `radius?: number` Corner radius of what it shines on, in px; the style's if not set.
- `color?: string` Colour of the glint (default a soft white).
- `children: ReactNode` What it shines across: a button, a logo, a price.

## Cursor · `graphics/cursor`

A macOS pointer gliding through points, with a press and a ripple on clicks.

`<Cursor points={[{x: 1300, y: 760, at: 0}, {x: 900, y: 430, at: 30, click: true}]} />`

- `points: CursorPoint[]` Where it goes: each point's `x` and `y` in px of its parent, the frame `at` it arrives there, and `click` to press there.
- `travel?: number` Frames it takes to move from one point to the next (default 22).
- `size?: number` Its size in px (default 40).
- `exit?: number` Frame it starts to leave; it stays to the end if not set.
- `light?: boolean` A white pointer with a dark edge, for dark footage; a black one if not set.

Also exports: `CursorPoint`

## Spotlight · `graphics/spotlight`

`<Spotlight rect={{x: 700, y: 300, width: 520, height: 260}} start={15} />`

- `rect: { x: number; y: number; width: number; height: number; }` The part to light, in px of the frame: `x`, `y`, `width`, `height`.
- `start?: number` Frame it starts on, counted from the start of its scene (default 0).
- `frames?: number` Frames the light takes to close in (default 26).
- `exit?: number` Frame it starts to leave; it stays to the end if not set.
- `dim?: number` How dark the rest of the frame gets, 0 to 1 (default 0.62).

- `radius?: number` Corner radius of the hole in px; the style's if not set.
- `ring?: boolean` Draw an accent outline round the hole (default true).

## Marquee · `graphics/marquee`

A row of words or logos sliding past for ever, its ends fading out.

`<Marquee items={['Fast', 'Private', 'Native', 'Open source']} />`

- `items: React.ReactNode[]` What slides past: strings are set in the headline face; pass elements for logos.
- `loop?: number` Seconds one full loop takes (default 9).
- `gap?: number` Space between items in px; 70% of `size` if not set.
- `reverse?: boolean` Slide the other way.
- `size?: number` Size of the words in px; 1.1 times the style's headline size if not set.
- `color?: string` Colour of the words; the style's ink if not set.
- `start?: number` Frame it starts on, counted from the start of its scene (default 0).
- `separator?: boolean` Put an accent dot between items (default true).
- `width?: string | number` Its width, in px or any CSS width (default '100%').
