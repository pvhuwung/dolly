# Transitions

GENERATED by `npm run library`: don't edit it. How one scene gives way to the next. A style picks one; a scene picks its own with `transition: '…'` (the one INTO that scene).

`preview.jpg` shows every one: each cell is an item's sample, labelled with its code.
