# Drawings

GENERATED by `npm run library`: don't edit it. Illustrations drawn with code that animate as they draw. They tint themselves toward the brand colour.

`preview.jpg` shows every one: each cell is an item's sample, labelled with its code.

## Paper · `drawings/paper`

A card of warm paper with grain, fibres and an uneven edge that slides in and holds a drawing.

`<Paper width={560} height={700} rotate={-3}><Flower /></Paper>`

- `width: number` Its width in px.
- `height: number` Its height in px.
- `rotate?: number` Tilt in degrees (default 0).
- `start?: number` Frame it starts on, counted from the start of its scene (default 0).
- `color?: string` The paper's colour (default a warm off-white, #f6f1e5).
- `seed?: number` Changes the grain and the edge; the same seed always draws the same.
- `padding?: number` Space between the card's edge and what's on it, in px (default 0).
- `style?: React.CSSProperties` Styles for the card's outer box, to place it.
- `children?: ReactNode` What sits on the card, centred.

Also exports: `noise`, `Palette`
