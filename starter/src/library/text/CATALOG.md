# Text

GENERATED by `npm run library`: don't edit it. Kinetic type: a headline that animates in with its accent phrase marked, words that mark themselves, a rotating word, a counter. The style picks the effect and the mark; props override them.

`preview.jpg` shows every one: each cell is an item's sample, labelled with its code.

## Kinetic · `text/kinetic`

A headline that comes in word by word or letter by letter the style's way, with its accent phrase marked as it lands.

`<Kinetic text="Approve it" accent="from your phone." start={10} exit={80} />`

- `text: string` The words, before the accent phrase.
- `accent?: string` The phrase set in the style's accent way.
- `effect?: TextEffect` How the words come in; the style's own if not set.
- `start?: number` Frame it starts on, counted from the start of its scene (default 0).
- `stagger?: number` Frames between one word (or letter) starting and the next; the effect's own if not set.
- `exit?: number` Frame it starts to leave; it stays to the end if not set.
- `mark?: MarkKind` What's drawn behind the accent phrase; the style's own if not set.
- `align?: 'left' | 'center'` Left-aligned or centred (default left).
- `style?: React.CSSProperties` CSS merged over the headline style: font size, colour, max width.

## Mark · `text/mark`

Draws a highlighter, block, pill, underline, circle, strike or box on any inline words at a given frame.

`<Mark kind="circle" start={40}>3×</Mark>`

- `kind: MarkKind` Which mark: marker, block, pill, underline, circle, strike or box.
- `start?: number` Frame its mark starts to draw, counted from the start of its scene (default 0).
- `color?: string` Its colour; the style's accent if not set (the alert colour for a strike).
- `children: ReactNode` The words, number or name to mark.

## Cycle · `text/cycle`

One slot in a line whose word changes every few frames, sliding the old word out and the new one in.

`<Cycle words={['fast.', 'polished.', 'yours.']} start={30} />`

- `words: string[]` The words it cycles through, in order; it loops.
- `every?: number` Frames each word holds before the next comes in; 45 times the style's pace if not set.
- `start?: number` Frame it starts on, counted from the start of its scene (default 0).
- `style?: React.CSSProperties` CSS merged over the headline and accent style: font size, colour.

## Counter · `text/counter`

A number counting up or down with easing, thousands separators and tabular figures, at a fixed width.

`<Counter to={12480} suffix="+" start={20} />`

- `to: number` The number it counts to.
- `from?: number` The number it counts from (default 0).
- `start?: number` Frame it starts on, counted from the start of its scene (default 0).
- `frames?: number` Frames the count takes; 50 times the style's pace if not set.
- `decimals?: number` Digits after the decimal point (default 0).
- `prefix?: string` Text before the number, like $.
- `suffix?: string` Text after the number, like + or %.
- `style?: React.CSSProperties` CSS merged over the headline style: font size, colour.
